# Improve connection recovery

Preserve the user's work when the desktop runtime reconnects.

## Keep drafts intact

Retain the current message and attachment references while fresh session state arrives.

## Refresh available chats

Update the chat list from the current registry. Keep the selected conversation when it is still available.

## Verify the recovery flow

Exercise successful reconnects, removed chats, and the empty-workspace state. Check keyboard focus at narrow widths.
