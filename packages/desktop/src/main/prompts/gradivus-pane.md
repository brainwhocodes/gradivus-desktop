Inspect and control only browser panes explicitly authorized by the user in Gradivus. Start with `list`, then use `observe` to get the current `documentEpoch` and stable element refs. Pass that exact epoch to every pane operation. Observe access allows `list`, `observe`, and `screenshot`; Control access additionally allows structured `act` and `navigate`. Navigation or page replacement invalidates old refs. The tool never exposes raw JavaScript, cookies, storage, clipboard, downloads, or file upload.
